## 排版规则

- 长卷（宽高比大于 1.5）在「整页淡底」下作为横幅铺在页面下方，上缘做渐隐；立轴满幅铺开并居中裁切。
- 「页眉页脚」取画面中段的横向条带；「四边」满幅铺开后只露出四周。
- 浓淡默认：卡片 30% 到 50%，描红纸页眉页脚 35% 到 40%。
